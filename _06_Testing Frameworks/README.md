# 6. Testing Frameworks

Testing is what allows you to sleep at night after a production deploy. 

### **Vitest / Jest**
- **Why use it:** `Jest` is the "batteries-included" standard. `Vitest` is the modern, faster alternative built on Vite, perfect for ESM-first projects.
- **Alternatives:** 
    - **Mocha:** Highly flexible, but requires separate assertion libraries (Chai) and mocking tools (Sinon).
    - **Supertest:** For integration testing HTTP endpoints.
- **Use Case:** Unit testing logic, integration testing APIs, and maintaining code quality through CI/CD.
